# PIRANT Kazakhstan — сайт, панель управления и сервер

Фронтенд: Vite + React 18 + TypeScript + Tailwind. Бэкенд: Node.js 20+ / Express + **PostgreSQL** (папка `server/`).

## Что делает сервер

- Хранит всё содержимое сайта (направления, новости, партнёры, настройки) и обращения в PostgreSQL.
- Заявки с сайта сохраняются **только на вашем сервере**; в WhatsApp/Telegram из формы ничего не уходит.
- Сотрудникам уходит уведомление «Новая заявка» (без имени, телефона и текста) в Telegram-бот и на почту.
- Вход в панель: пароль (scrypt) + код из приложения-аутентификатора (TOTP), 8 резервных кодов, блокировка на 15 мин после 5 неверных попыток, журнал действий. Сессия — httpOnly-cookie на 8 часов.
- Роли: `superadmin` (всё), `manager` (направления, новости, обращения).
- Загрузка изображений: файлы лежат в `server/uploads`, на сайт отдаются по `/uploads/...`.

## Запуск у себя на компьютере

Нужны Node.js 20+ и PostgreSQL 14+.

```bash
# 1. База
createuser pirant --pwprompt           # пароль запомните
createdb pirant -O pirant

# 2. Сервер
cd server
cp .env.example .env                   # заполните DATABASE_URL, ADMIN_PASSWORD
# JWT_SECRET и APP_ENC_KEY:  openssl rand -hex 32   (для каждого свой)
# в разработке поставьте NODE_ENV=development
npm install
npm run migrate                        # создаёт таблицы
npm run seed                           # загружает начальное содержимое сайта
npm run create-admin                   # создаёт суперадмина (ADMIN_LOGIN / ADMIN_PASSWORD из .env)
npm run dev                            # API на http://localhost:3001

# 3. Сайт (в другом терминале, из корня проекта)
npm install
npm run dev                            # http://localhost:5173, панель: /admin
```

При первом входе панель предложит отсканировать QR-код в приложении-аутентификаторе и покажет резервные коды — сохраните их.

## Telegram-бот (внутренние уведомления)

1. В Telegram найдите `@BotFather`, отправьте `/newbot`, получите токен.
2. Токен впишите **только** в `server/.env` (`TELEGRAM_BOT_TOKEN=`) на сервере. Никому его не отправляйте; при утечке — перевыпустите у BotFather.
3. Перезапустите сервер. Сотрудники пишут боту `/start` (или бота добавляют в рабочую группу).
4. В панели → **Уведомления** суперадмин подтверждает получателей. Подтверждённые получают сообщение о каждой новой заявке.

Бот работает через long polling, домен и вебхук не нужны. Серверы Telegram находятся за пределами Казахстана — в сообщение попадает только фраза «Новая заявка» и ссылка, но решение лучше согласовать со специалистом по ИБ.

## Почта

В `.env` задайте `SMTP_*`, `MAIL_FROM` и `NOTIFY_EMAILS` (адреса через запятую). Без них письма не отправляются, остальное работает.

## WhatsApp позже

Канал уведомлений добавляется одной функцией: см. `server/src/notify.ts` (массив `channels`, там оставлена закомментированная строка). Переделывать остальное не нужно.

## Перед публикацией

- Логотипы партнёров низкого разрешения (вырезаны из презентации) — замените в панели → «Партнёры».
- Публичный сайт поддерживает русский, казахский и английский языки. Для новых или изменяемых материалов заполняйте все три языковых поля в панели управления; встроенные тексты без языковых полей переводятся словарём сайта.
- Проверьте, что в панели → «Контакты» заполнены WhatsApp и почта.
- SVG-изображения из панели на сервер не загружаются (в SVG может быть скрипт): используйте WebP/PNG/JPEG.
